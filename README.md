# НейроМульт 3D — Живые Истории в Claude

Скилл для полного цикла создания вирусных вертикальных анимационных роликов (Shorts / Reels / Клипы) в Claude.

Позволяет создавать сюжетные вертикальные мульт-истории длительностью **55–70 секунд** в стилистике **«2D-персонажи внутри живописного 3D-мира»**: плоские рисованные герои с живым тушевым контуром, фактурный 3D-город с ручной росписью текстур и чернильной обводкой геометрии, оптическое размытие глубины резкости (DoF), плавные пролёты камеры, процедурный синтез маршевой музыки и звуковых эффектов. Весь рендеринг выполняется локально на ПК через связку **Three.js + Remotion** — без сторонних видео-генераторов.

Пайплайн отработан и выверен на эталонном проекте **«Мост, который рухнул от песни»** (`The Bridge That Fell for a Song`) — 67-секундном историческом шортсе о Бротонском подвесном мосте 1831 года.

## Состав пакета

| Путь | Назначение |
|---|---|
| `SKILL.md` | Главная инструкция скилла: пошаговый конвейер, художественные нормативы, защита от типовых ошибок и финальные коэффициенты рендера |
| `templates/bridge/` | Полный исходный код эталонного ролика: 3D-мир, генератор персонажей, шейдер туши, боке-размытие, цветокоррекция, сценарий и ключи камеры |
| `templates/audio/` | Движок процедурного звука на Python: синтез SFX, маршевая партитура, автоматический дакинг под голос и мастеринг по LUFS |
| `templates/scripts/` | Утилиты рендера превью-кадров, склейки песочниц, генерации сравнительных листов (side-by-side) и покадрового ОТК (QA) |
| `references/STYLE_BIBLE.md` | Формула драматургии и визуального стиля, выведенная на основе замеров 20 эталонных роликов |
| `references/reports/` | Семь инженерных отчётов с точными метриками: движение камеры, глубина резкости, текстуры, персонажи, свет, контуры, грейдинг |
| `references/frames/` | 38 полноразмерных референсных кадров (540×960) для визуальной калибровки |
| `references/sheets/` | 20 раскадровочных контакт-листов (по 60 кадров на ролик, суммарно 1 200 кадров) |

## Установка и запуск

1. Скопируйте папку скилла в директорию навыков: `~/.claude/skills/neuromult-3d-claude/` (или подключите из `A:\CLAUDE\SKILLS\neuromult-3d-claude`).
2. Убедитесь, что в системе установлены [Remotion](https://www.remotion.dev/) с пакетом `@remotion/three`, **Node.js**, **Python 3** и **ffmpeg**.
3. В чате с Claude напишите: *«Используй скилл НейроМульт 3D и сделай историю про…»*.

Claude пройдёт весь пайплайн из `SKILL.md`: подберёт достоверный физический/исторический парадокс, напишет сценарий, синхронизирует пословный тайминг озвучки, соберёт 3D-сцену и раскадровку в `story.ts`, отрендерит контрольные кадры для сверки с эталоном и выдаст финальный мастер-файл в **2K (1440×2560)** со сведённым звуком.

---

## Важные примечания

- **Временная папка Remotion:** обязательно направляйте `REMOTION_TMP` (`TEMP`/`TMP`) на вместительный диск. При каждой сборке бандла Remotion копирует папку `public/` (~1,3 ГБ) во временную директорию.
- **Оригинальность контента:** референсные материалы служат исключительно для калибровки визуального шейдинга, света и динамики камеры. Сюжет, текст, герои и озвучка всегда создаются с нуля.
